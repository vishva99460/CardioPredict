About CardioPredict

Cardiovascular Disease Risk Prediction System

About the Project

CardioPredict is a machine learning based web application designed to predict cardiovascular disease risk using selected health-related input parameters.

The project demonstrates the machine learning workflow, including data preprocessing, exploratory data analysis, model training, evaluation and deployment through a web interface.

Our Objective

The main objective of CardioPredict is to provide a simple and user-friendly interface where users can enter relevant health information and receive a machine learning based prediction.

Key Features

Easy to Use

Simple interface for entering health-related information.

Machine Learning

Uses a trained classification model for prediction.

Fast Prediction

Provides prediction results through the web application.

Web Based

Built using Flask with a responsive interface.

Technologies Used

  • Python
  • Pandas and NumPy
  • Scikit-learn
  • Random Forest Classification
  • Flask
  • HTML and CSS
  • GitHub and Render
