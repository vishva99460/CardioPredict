
# Cardiovascular Disease Prediction

## Project Overview
A Machine Learning project that predicts the possibility of cardiovascular disease using patient health information.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML/CSS
- Matplotlib
- Seaborn

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. Gradient Boosting

## Preprocessing
- Duplicate removal
- Outlier filtering
- Age conversion
- Data splitting
- Feature scaling

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Cross-validation

## Deployment
The model is integrated with a Flask web application.

## Disclaimer
This project is for educational purposes only and is not a medical diagnosis tool.
